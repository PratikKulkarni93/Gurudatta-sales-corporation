PUT THE DISTRICT / GOVERNMENT LOGOS IN THIS FOLDER
===================================================
Save each logo as a PNG (square or round, about 200x200 px, transparent background is best)
with EXACTLY these file names:

  dharashiv.png
  parbhani.png
  latur.png
  amravati.png
  chhatrapati-sambhajinagar.png
  nandurbar.png
  maharashtra.png      <- state logo, used automatically when a district logo is missing

If a district logo file is missing, the site shows the Maharashtra logo.
If that is missing too, it shows a coloured badge with the district initials (e.g. LA, PA).
No code change is needed - just add the files and refresh the page.
